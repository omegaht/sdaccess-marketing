# SD ACCESS — Sitio web

Sitio de marketing estático de SD ACCESS (Inicio, Productos, Instalaciones, Nosotros, Contacto).
No requiere build ni servidor: son archivos HTML/CSS/JS que se pueden publicar en cualquier
hosting estático (Netlify, Cloudflare Pages, GitHub Pages, S3 + CloudFront, etc.).

Extraído de `SDAccessWebPage` sin el portal de soporte (login/portal y servidor Express).

## Vista previa local

```sh
npx serve .
# o
python3 -m http.server 8080
```
